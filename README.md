## Overview

**Anaconda Cybersecurity Guide** is designed for penetration testers, cybersecurity engineers, students, and enthusiasts.  
It provides practical, executable content (attack playbooks), tool explanations, and real-world scenarios.

This repository is ideal for those who want to:

- Learn penetration testing step-by-step.
- Build a local lab environment.
- Understand real attack chains and apply them safely.

> **Disclaimer:** This project is for educational and authorized testing only. Misuse is strictly prohibited.

---

## Key Features

- Over **100 cybersecurity tools**, categorized and documented.
- Practical examples for each tool.
- Realistic attack-chain playbooks.
- Lab setup scripts using VirtualBox, VMware, and Docker.
- Ready automation scripts (Bash/Python).

## Quick Start

### Requirements

- Linux (Ubuntu / Debian / Kali) or Virtual Machine
- Python 3.10+
- Git
- Docker (optional)

### Installation

```bash
git clone https://github.com/kl0l69/anaconda-cyber.git
cd anaconda-cyber
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
````

### Example Recon Scan

```bash
nmap -sC -sV -T4 --open 10.0.2.15
```

### Example SQLMap

```bash
sqlmap -u "http://10.0.2.15/vuln.php?id=1" --batch --dbs
```
